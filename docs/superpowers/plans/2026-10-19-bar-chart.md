# Bar chart with avg + max

Approved by the user 2026-10-19. Branch `feat/pve-widget`.

## Why
The series is downsampled by averaging ~15 one-minute AVERAGE rows into each of 96 buckets. On live data the CPU peak of 92% becomes 48%, so the widget looks much smoother than the Proxmox UI. The user wants bars: avg opaque, max semi-transparent on top.

## Collector (`collector/pvewidget/build.py`)
- Each series point becomes `[t, avg, max]`:
  - `avg` = mean of the bucket's AVERAGE rows (as now).
  - `max` = max of the bucket's MAX rows, over the same time range (assign MAX rows to buckets by time, using the AVERAGE bucket boundaries). Missing MAX data for a bucket → `max = avg`.
  - Same `denom_key` handling and gap skipping as now.
- Applies to host CPU, host RAM and guest CPU series. `avg` and `peak` scalars are unchanged.
- Snapshot `schema` stays `1` (the app accepts both shapes).
- Tests:
  - `[t, avg, max]` shape, with `max >= avg` for every point.
  - On the fixtures, host CPU series max over points equals `stats()` peak when the same rows are passed as avg and max.
  - A bucket with no MAX rows falls back to `avg`.
  - Regenerate the golden file `app/Tests/Fixtures/snapshot.json`.
- Deploy with `collector/deploy/deploy.sh` (pre-approved; touch nothing else on pve). Verify that `systemctl is-active pvewidget` reports active and that the Mac `curl` returns 200 with 3-element points.

## App
- `Point` gets `avg: Double` and `max: Double`.
  - It decodes `[t, avg, max]`, or legacy `[t, v]` with `max = avg`.
  - Keep `v` as an alias for `avg` only if it reduces churn.
- Replace the line/area chart with a bar chart (rename `ThresholdLineChart` → `ThresholdBarChart`, update call sites):
  - Per point, an opaque bar `0…avg`, plus a semi-transparent bar `avg…max` (about 0.35 opacity) stacked on top.
  - Each bar segment is colored by the level of its own top value (`avg` for the base and `max` for the overlay), using the chart's `Threshold`: green / yellow / red.
  - Y domain is fixed at `0…1`. Values above 1 are clamped.
  - Bars fill the width with a small gap and no axes, like the current chart.
- Used everywhere the line chart was: host CPU, host RAM, and the guest mini charts.
- Accented (desaturated) mode: the base uses `.widgetAccentable()`; the overlay stays semi-transparent.
